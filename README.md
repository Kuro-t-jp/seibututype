# 生物タイピング

高校「生物基礎・生物」の用語学習と、学習に合わせて育つバイオームのアプリです。

**[アプリを開く](https://kuro-t-jp.github.io/seibututype/)**

## 学習

- 850語のタイピング・4択・記述練習
- 思考問題、共通テストを参考にした独自の5択演習
- 苦手の復習、復習ノート、単元別の学習記録
- 「生物基礎全部」「生物全部」に取り組む超挑戦モード

## バイオーム

- 生物120種類（植物45・動物39・観察生物36）、背景20種類、図鑑140ページ
- 学習 → コイン → 確率で発見 → 育成・図鑑登録、重複や不要なストックは経験値へ
- 未獲得の名前と姿は発見まで秘密。初獲得・グレード別の登場演出
- 出典付きの解説カードと確認問題。生成画像はゲーム用のイラストで、厳密な同定図ではありません
- タイピング15問ノーミス完走は強化なし34コイン。クイズ・記述の同条件は68コイン
- レベル1の生物発見グレードは86%・13%・1%、背景C/B/A/Sは80%・16%・3.5%・0.5%

## 記録と公開版

学習履歴・コイン・図鑑は、そのブラウザの保存領域に記録します。別の端末、ブラウザ、GAS版との自動同期はありません。ブラウザのサイトデータを削除すると記録も消えます。

Pages版・GAS版ともに名前登録と共有ランキングはありません。学習記録を運営者へ送信せず、学習・ショップ・育成を利用できます。GAS版を用意する場合は [GAS_SETUP.md](GAS_SETUP.md) を参照してください。

## 開発

公開する実行ファイルはルートの `index.html` です。画像・問題・スクリプトを内蔵し、追加の外部配信サービスは不要です。

```sh
python3 tools/build.py --check
python3 tools/build.py
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/biome-economy.cjs
node tests/biome-art.cjs
python3 -m http.server 8766
```

`data/` に教材データ、`src/` に機能別ソース、`assets/` に再ビルド用の画像があります。ブラウザテストにはPlaywrightとChromeが必要です。GitHub Pagesは `main` ブランチのルートを公開します。

アカウント別のバックアップ、操作ログ、個人の学習記録は、この公開リポジトリに含めていません。

### 保存失敗と複数タブへの対応

購入の保存に失敗した場合はコイン・購入状態を戻し、成功演出を出しません。学習記録や報酬が保存できない場合は画面に表示し、同じ画面から再保存できます。古いタブの購入操作は最新記録を上書きせず中止します。学習履歴・ノート・超挑戦は別タブで保存された記録を取り込んでから変更を保存します。未保存のまま画面を閉じると記録が失われるため、再保存が完了するまで画面を開いたままにしてください。
