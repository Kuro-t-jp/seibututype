# 生物タイピング

高校生物・生物基礎の重要用語 **724 語** を、3つの遊び方で練習できる Web アプリです。

Google Apps Script のウェブアプリとしても、GitHub Pages などの静的サイトとしても、
**同じ `index.html` がそのまま動きます**（ランキングだけウェブアプリ版限定）。

👉 **[アプリを開く](https://USERNAME.github.io/REPO/)**

## 3つの遊び方

| モード | 内容 |
|---|---|
| ⌨️ **タイピング** | 用語と意味を見て、読み方をローマ字で打つ |
| ❓ **一問一答クイズ** | 説明文から用語を4択で答える（<kbd>1</kbd>〜<kbd>4</kbd>キー対応） |
| ✍️ **記述クイズ** | 説明文から用語を思い出して入力（<kbd>Tab</kbd>でヒント） |

出題モードは **タイムアタック60秒 / じっくり120秒 / 15問チャレンジ** の3種類。
カテゴリは10分類から複数選択できます。

## そのほかの機能

- **コイン & ショップ** … プレイで貯めたコインで、生物用語の名前がついたパワーアップ（ATP・ミトコンドリア・細胞膜…）とテーマ配色を解放。効果は入手するまで伏せられています
- **共有ランキング** … 名前を登録すると、3モードそれぞれで TOP5 と自分の順位が出ます（ウェブアプリ版のみ）
- **柔軟なローマ字判定** … `shi`/`si`、`tsu`/`tu`、`ji`/`zi`、`n`/`nn`、促音・拗音・長音のどれでもOK
- **Chromebook 対応** … 横長・低い画面でも1画面に収まるよう自動で圧縮

## 用語を追加・修正する

1. `data/words.json` を編集する

   ```json
   {
     "c": "細胞",                        // 分類（上の表の10種類のいずれか）
     "t": "細胞膜",                      // 用語（答え）
     "y": "さいぼうまく",                 // よみ（ひらがな・入力対象）
     "m": "細胞を包み物質の出入りを調節する膜"  // 説明文
   }
   ```

2. ビルドして `index.html` に反映する

   ```bash
   python3 tools/build.py
   ```

   重複した用語・未知の分類・ひらがなでないよみがあるとエラーで止まります。

## 公開のしかた

### GitHub Pages（誰でも遊べる練習用）

1. リポジトリを GitHub にプッシュ
2. **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして Save
4. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

ランキングは自動的に「ウェブアプリ版で使えます」の表示に切り替わり、それ以外は全機能そのまま動きます。

### Google Apps Script（授業用・ランキングつき）

1. Apps Script プロジェクトに `Code.gs` と、`index.html`（ファイル名は `index`）を置く
2. **デプロイ → 新しいデプロイ → ウェブアプリ**
3. **実行するユーザー：自分**、**アクセスできるユーザー：全員**（または校内ドメイン）
4. 発行された URL を生徒に配布

「実行するユーザー：自分」にすることで全員のスコアが同じ場所に集まり、生徒側での権限許可も不要になります。
ランキングを消したいときは、エディタで `resetRanking` を手動実行してください。

## ファイル構成

```
index.html        アプリ本体（データ・CSS・JSをすべて内包／これ1つで動く）
Code.gs           GAS ウェブアプリ版のサーバー側（ランキング）
data/words.json   用語データ 724語
tools/build.py    data/words.json → index.html の WORDS 配列を差し替える
```

## データについて

収録した用語は高校生物・生物基礎の標準的な学習用語です。説明文はすべて本リポジトリのために
書き下ろしたもので、特定の教科書・問題集の文章を転載したものではありません。
